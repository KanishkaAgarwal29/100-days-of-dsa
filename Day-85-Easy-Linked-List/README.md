# 🚀 Day 85 – Easy Linked List Problems

Today I solved four Linked List problems focused on basic traversal, simulation, and pointer manipulation. This was a lighter practice session aimed at strengthening core concepts before moving on to more advanced problems.

## 📌 Problems Solved

1. Design Browser History
2. Convert Binary Number in a Linked List to Integer
3. Delete Nodes From Linked List Present in Array
4. Merge Nodes in Between Zeros

---

### 1. Design Browser History
Designed a browser history system supporting visit, back, and forward operations. The problem focused on maintaining navigation history efficiently while simulating real-world browser behavior.

### 2. Convert Binary Number in a Linked List to Integer
Converted a binary number stored as a linked list into its decimal representation by traversing the list and processing each bit. It was a simple problem to practice traversal and bit manipulation.

### 3. Delete Nodes From Linked List Present in Array
Removed all nodes whose values were present in a given array using a HashSet for efficient lookups. This problem combined linked list traversal with hash-based optimization.

### 4. Merge Nodes in Between Zeros
Merged values between consecutive zero nodes by calculating their sum and constructing the required linked list. It reinforced traversal, accumulation, and pointer updates.

Today's problems emphasized that not every Linked List challenge requires complex algorithms. Many problems can be solved efficiently through careful traversal, appropriate data structures, and clean pointer manipulation.
