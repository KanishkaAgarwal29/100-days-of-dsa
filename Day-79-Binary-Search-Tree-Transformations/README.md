---

## 🧠 Key Concepts

- Inorder Traversal
- Reverse Inorder Traversal
- BST Properties
- Tree Transformation
- Range-Based Pruning
- Cumulative Sum

---

## 💡 Key Learning

Today's problems showed how the sorted property of a Binary Search Tree can be used to perform different transformations efficiently.

Inorder traversal helped in restructuring and arranging BST nodes, while reverse inorder traversal was useful for maintaining cumulative sums in the Greater Sum Tree problem.

---

## 📊 Complexity

| Problem | Time | Space |
|---|---|---|
| Balance a Binary Search Tree | O(n) | O(n) |
| Increasing Order Search Tree | O(n) | O(h) |
| Trim a Binary Search Tree | O(n) | O(h) |
| BST to Greater Sum Tree | O(n) | O(h) |

> `h` = height of the tree.

---

## 🎯 Takeaway

The BST property makes many tree transformations much simpler. Inorder traversal gives sorted order, while reverse inorder traversal allows processing nodes from the largest value to the smallest.
