# 🚀 Day 88 – Graphs (DFS Basics)

Today I started the Graphs journey by solving two fundamental DFS-based problems. These problems introduced graph traversal, connected components, and grid-based exploration, forming the foundation for more advanced graph algorithms.

## 📌 Problems Solved

1. Number of Provinces
2. Flood Fill

---

### 1. Number of Provinces
Identified the number of connected components in an undirected graph represented as an adjacency matrix using Depth First Search (DFS). This problem introduced the concept of graph traversal and visited node tracking.

### 2. Flood Fill
Applied DFS on a 2D grid to recolor all connected cells having the same initial color. The problem strengthened grid traversal skills and handling movement in four directions.

---

## 🧠 Key Concepts

- Graph Representation
- Depth First Search (DFS)
- Connected Components
- Grid Traversal
- Direction Arrays
- Visited Nodes

---

## 💡 Key Learning

Today's problems built the foundation of Graph traversal. Although one problem used an adjacency matrix and the other a 2D grid, both relied on the same DFS traversal pattern, showing how a single algorithm can solve different types of graph problems.

---

## 📊 Complexity

| Problem | Time | Space |
|----------|------|-------|
| Number of Provinces | O(V²) | O(V) |
| Flood Fill | O(m × n) | O(m × n) |

---

## 🎯 Takeaway

Graphs may seem different from Trees at first, but DFS follows a very similar recursive traversal pattern. Understanding this fundamental technique will make upcoming graph problems much easier to approach.
