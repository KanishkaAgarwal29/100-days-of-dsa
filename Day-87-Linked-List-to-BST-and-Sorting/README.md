# 🚀 Day 87 – Advanced Linked List Applications

Today I solved two advanced Linked List problems that combined linked lists with divide-and-conquer techniques and binary search tree construction.

## 📌 Problems Solved

1. Convert Sorted List to Binary Search Tree
2. Sort List

---

### 1. Convert Sorted List to Binary Search Tree
Converted a sorted linked list into a height-balanced Binary Search Tree by repeatedly finding the middle node using the Fast & Slow Pointer technique. This problem demonstrated how linked lists and trees can be combined to build balanced structures efficiently.

### 2. Sort List
Sorted a linked list using Merge Sort, one of the most efficient sorting algorithms for linked lists. The solution involved splitting the list into halves, recursively sorting each half, and merging the sorted lists.

---

## 🧠 Key Concepts

- Fast & Slow Pointer
- Divide and Conquer
- Merge Sort
- Balanced Binary Search Tree
- Recursion
- Linked List Splitting

---

## 💡 Key Learning

Today's problems showed how linked lists can be integrated with other data structures and algorithms. Using the Fast & Slow Pointer technique for tree construction and Merge Sort for efficient sorting reinforced the importance of divide-and-conquer strategies in linked list problems.

---

## 🎯 Takeaway

Linked Lists are not limited to traversal and pointer manipulation. They can also serve as the foundation for building balanced trees and implementing efficient sorting algorithms, making them a versatile data structure in problem solving.
