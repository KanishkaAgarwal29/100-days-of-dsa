# 🚀 Day 100 – Arithmetic Progression & Pascal's Triangle

Today I completed my **100 Days of DSA Challenge** with two Easy problems focused on array construction and mathematical patterns.

## 📌 Problems Solved

1. Can Make Arithmetic Progression From Sequence
2. Pascal's Triangle

---

### 1. Can Make Arithmetic Progression From Sequence
Used the minimum and maximum values to determine the common difference and mapped each element to its expected position. This avoids sorting and solves the problem in O(n) time.

### 2. Pascal's Triangle
Constructed each row using the previous row. The first and last elements are always `1`, while the middle elements are calculated by adding adjacent values from the previous row.

## 📊 Complexity

### Can Make Arithmetic Progression From Sequence
- Time: O(n)
- Space: O(n)

### Pascal's Triangle
- Time: O(numRows²)
- Space: O(numRows²)
