# 🚀 Day 86 – Advanced Linked List Concepts

Today I solved two interview-focused Linked List problems that introduced advanced pointer manipulation and efficient component identification.

## 📌 Problems Solved

1. Copy List with Random Pointer
2. Linked List Components

---

### 1. Copy List with Random Pointer
Created a deep copy of a linked list containing both `next` and `random` pointers without using extra space for node mapping. This problem strengthened my understanding of in-place node interleaving and careful pointer manipulation.

### 2. Linked List Components
Counted the number of connected components formed by a given subset of node values using a HashSet for efficient lookups. The problem reinforced linked list traversal combined with hash-based optimization.

---

## 🧠 Key Concepts

- Deep Copy of Linked Lists
- Random Pointer Handling
- In-place Pointer Manipulation
- HashSet
- Linked List Traversal
- Component Identification

---

## 💡 Key Learning

Today's problems highlighted two different aspects of Linked Lists. While one required careful manipulation of multiple pointers to clone a complex data structure, the other demonstrated how combining a Linked List with a HashSet can simplify traversal-based problems.
